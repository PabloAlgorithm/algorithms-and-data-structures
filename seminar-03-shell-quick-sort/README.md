# Семинар 3. Улучшенные методы сортировок и unit-тесты на C++

Дисциплина: Алгоритмы и структуры данных.

## Что реализовано

Два улучшенных алгоритма сортировки, каждый оформлен отдельной библиотекой (пара файлов `.h` + `.cpp`) в виде шаблонной функции:

| Алгоритм | Функция | Файлы |
|---|---|---|
| Метод Шелла | `shellSort` | `shell_sort.h / .cpp` |
| Быстрая сортировка | `quickSort` | `quick_sort.h / .cpp` |

Обе функции имеют одинаковый вид и сортируют массив по возрастанию:

```cpp
template <typename T>
void quickSort(T* array, int size);
```

Объявление шаблона находится в `.h`, реализация в `.cpp`. В конце каждого `.cpp` выполнено явное инстанцирование шаблона для типов `int`, `long long`, `float`, `double`, `char`, `std::string`.

## Описание алгоритмов

- **Метод Шелла.** Улучшение сортировки вставками: сначала вставками сортируются элементы, отстоящие друг от друга на шаг `gap`, затем шаг уменьшается. Последовательность шагов: `size/2, size/4, ..., 1`. На последнем проходе с шагом 1 массив уже почти упорядочен.
- **Быстрая сортировка.** Выбирается опорный элемент (из середины участка), массив разделяется на две части - не больше опорного и не меньше опорного, после чего каждая часть сортируется рекурсивно. В среднем O(n log n), в худшем случае O(n^2).

## Структура

```
ShellQuickSort.sln         решение Visual Studio (два проекта)
enhanced_sorting/          проект EnhancedSorting - статическая библиотека с сортировками
    include/               заголовочные файлы
    src/                   файлы реализации
tests/                     проект Tests - unit-тесты
    test_sorts.cpp         тесты обеих сортировок
```

Библиотека тестирования Catch2 лежит в корне репозитория в папке `catch2/` и общая для всех семинаров.

## Тесты

Используется Catch2. Для каждой сортировки написано 13 тестов (всего 26) по схеме Arrange - Act - Assert: массив из варианта 13 `[11, 7, 14, 20, 5, 1, 15, 9]`, пустой массив, нулевой указатель, один элемент, два элемента, уже отсортированный массив, массив в обратном порядке, дубликаты и отрицательные числа, одинаковые элементы, тип `double`, тип `std::string`, сравнение с `std::sort` на массиве из 1000 элементов. Дополнительно: для метода Шелла - маленькие элементы в конце массива, для быстрой сортировки - много элементов, равных опорному.

## Запуск

Открыть `ShellQuickSort.sln` в Visual Studio и собрать решение (Ctrl+Shift+B). Тесты запускаются автоматически после сборки проекта Tests (событие после сборки `"$(TargetPath)"`), результат выводится в окно «Вывод».
