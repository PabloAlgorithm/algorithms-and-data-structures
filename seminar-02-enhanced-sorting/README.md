# Семинар 2. Улучшенные методы внутренней сортировки и unit-тесты на C++

Дисциплина: Алгоритмы и структуры данных.

## Что реализовано

Два улучшенных алгоритма сортировки, каждый оформлен отдельной библиотекой (пара файлов `.h` + `.cpp`) в виде шаблонной функции:

| Алгоритм | Функция | Файлы |
|---|---|---|
| Сортировка вставкой с бинарным поиском | `binaryInsertionSort` | `binary_insertion_sort.h / .cpp` |
| Сортировка шейкером (двунаправленный пузырёк) | `shakerSort` | `shaker_sort.h / .cpp` |

Обе функции имеют одинаковый вид и сортируют массив по возрастанию:

```cpp
template <typename T>
void shakerSort(T* array, int size);
```

Объявление шаблона находится в `.h`, реализация в `.cpp`. В конце каждого `.cpp` выполнено явное инстанцирование шаблона для типов `int`, `long long`, `float`, `double`, `char`, `std::string`.

## В чём улучшения

- **Вставка с бинарным поиском.** Место вставки в отсортированной части ищется бинарным поиском, а не последовательным просмотром: O(log n) сравнений на элемент вместо O(n).
- **Шейкер.** Проходы чередуются слева направо и справа налево, поэтому маленькие элементы из конца массива быстро попадают в начало. Границы неотсортированной части сдвигаются до места последнего обмена; если обменов не было, сортировка завершается.

## Структура

```
EnhancedSorting.sln            решение Visual Studio (два проекта)
enhanced_sorting/              проект EnhancedSorting - статическая библиотека с сортировками
    include/                   заголовочные файлы
    src/                       файлы реализации
tests/                         проект Tests - unit-тесты
    test_enhanced_sorts.cpp    тесты обеих сортировок
```

Библиотека тестирования Catch2 лежит в корне репозитория в папке `catch2/` и общая для всех семинаров.

## Тесты

Используется Catch2. Для каждой сортировки написано 13 тестов (всего 26) по схеме Arrange - Act - Assert: массив из варианта 13 `[11, 7, 14, 20, 5, 1, 15, 9]`, пустой массив, нулевой указатель, один элемент, два элемента, уже отсортированный массив, массив в обратном порядке, дубликаты и отрицательные числа, одинаковые элементы, тип `double`, тип `std::string`, сравнение с `std::sort` на массиве из 1000 элементов. Дополнительно: для вставки с бинарным поиском - элементы у границ бинарного поиска, для шейкера - наименьший элемент в конце массива.

## Запуск

Открыть `EnhancedSorting.sln` в Visual Studio и собрать решение (Ctrl+Shift+B). Тесты запускаются автоматически после сборки проекта Tests (событие после сборки `"$(TargetPath)"`), результат выводится в окно «Вывод».
