# Алгоритмы и структуры данных

Семинарские задания по дисциплине «Алгоритмы и структуры данных», 2 курс.

Каждый семинар лежит в отдельной папке со своим решением Visual Studio. Весь код покрыт unit-тестами на Catch2.

| Семинар | Тема | Папка |
|---|---|---|
| 1 | Алгоритмы сортировки (вставками, выбором, обменом, пузырьком, улучшенным пузырьком) и unit-тесты | [seminar-01-sorting](seminar-01-sorting) |
| 2 | Улучшенные методы внутренней сортировки (вставка с бинарным поиском, шейкер) и unit-тесты | [seminar-02-enhanced-sorting](seminar-02-enhanced-sorting) |
| 3 | Улучшенные методы сортировок (метод Шелла, быстрая сортировка) и unit-тесты | [seminar-03-shell-quick-sort](seminar-03-shell-quick-sort) |

## Как запустить

1. Открыть файл `.sln` из папки нужного семинара в Visual Studio.
2. Собрать решение (Ctrl+Shift+B).
3. Тесты запускаются автоматически после сборки, результат выводится в окно «Вывод».

## Общие файлы

- `catch2/catch.hpp` - библиотека тестирования Catch2 (v2, один заголовок), общая для всех семинаров.
- `.gitignore` - исключает из репозитория служебные файлы Visual Studio и результаты сборки.
