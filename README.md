# Алгоритмы и структуры данных

Семинарские задания и лабораторные работы по дисциплине «Алгоритмы и структуры данных», 2 курс.

Каждая работа лежит в отдельной папке со своим решением Visual Studio. Для проверки кода используются unit-тесты на Catch2.

## Семинарские задания

| Семинар | Тема | Папка |
|---|---|---|
| 1 | Алгоритмы сортировки (вставками, выбором, обменом, пузырьком, улучшенным пузырьком) и unit-тесты | [seminar-01-sorting](seminar-01-sorting) |
| 2 | Улучшенные методы внутренней сортировки (вставка с бинарным поиском, шейкер) и unit-тесты | [seminar-02-enhanced-sorting](seminar-02-enhanced-sorting) |
| 3 | Улучшенные методы сортировок (метод Шелла, быстрая сортировка) и unit-тесты | [seminar-03-shell-quick-sort](seminar-03-shell-quick-sort) |
| 4 | Внешние сортировки (двухфазное и однофазное простое слияние, естественное слияние) и unit-тесты | [seminar-04-external-sorting](seminar-04-external-sorting) |

## Лабораторные работы

| Лабораторная | Тема и вариант | Папка |
|---|---|---|
| 1 | Обработка строки символов различными способами хранения. Вариант 13: найти самое длинное слово и удалить его, если оно содержит более 5 символов и не начинается с гласной буквы | [lab-01-strings](lab-01-strings) |

В лабораторной №1 реализованы три программы: обработка массива символов с отдельной длиной, C-строки с завершающим `\0` и строки из файла. Поддерживаются русский и английский текст в UTF-8. Обработка выполняется без дополнительных массивов. Подробности и тестовые сценарии находятся в папке работы.

## Как запустить

1. Открыть файл `.sln` из папки нужного семинара или лабораторной работы в Visual Studio.
2. Собрать решение (Ctrl+Shift+B).
3. Тесты запускаются автоматически после сборки проекта тестов, результат выводится в окно «Вывод».
4. Для лабораторной №1 выбрать запускаемый проект: `ArrayProgram`, `CStringProgram` или `FileProgram`, затем нажать Ctrl+F5. Инструкция по входному и выходному файлам приведена в README лабораторной.

## Общие файлы

- `catch2/catch.hpp` - библиотека тестирования Catch2 (v2, один заголовок), общая для семинаров и лабораторных работ.
- `.gitignore` - исключает из репозитория служебные файлы Visual Studio и результаты сборки.
