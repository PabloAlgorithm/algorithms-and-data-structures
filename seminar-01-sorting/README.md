# Семинар 1. Алгоритмы сортировки и unit-тесты на C++

Дисциплина: Алгоритмы и структуры данных.

## Что реализовано

Пять алгоритмов сортировки, каждый оформлен отдельной библиотекой (пара файлов `.h` + `.cpp`) в виде шаблонной функции:

| Алгоритм | Функция | Файлы |
|---|---|---|
| Сортировка вставками | `insertionSort` | `insertion_sort.h / .cpp` |
| Сортировка выбором | `selectionSort` | `selection_sort.h / .cpp` |
| Сортировка обменом | `exchangeSort` | `exchange_sort.h / .cpp` |
| Сортировка пузырьком | `bubbleSort` | `bubble_sort.h / .cpp` |
| Сортировка пузырьком с улучшениями | `optimizedBubbleSort` | `optimized_bubble_sort.h / .cpp` |

Все функции имеют одинаковый вид и сортируют массив по возрастанию:

```cpp
template <typename T>
void insertionSort(T* array, int size);
```

Объявление шаблона находится в `.h`, реализация в `.cpp`. В конце каждого `.cpp` выполнено явное инстанцирование шаблона для типов `int`, `long long`, `float`, `double`, `char`, `std::string`.

## Структура

```
SortingAlgorithms.sln      решение Visual Studio (два проекта)
sorting/                   проект Sorting - статическая библиотека с сортировками
    include/               заголовочные файлы
    src/                   файлы реализации
tests/                     проект Tests - unit-тесты
    test_sorts.cpp         тесты всех сортировок
```

Библиотека тестирования Catch2 лежит в корне репозитория в папке `catch2/` и общая для всех семинаров.

## Тесты

Используется Catch2. Для каждой сортировки написано 12 тестов (всего 60) по схеме Arrange - Act - Assert: массив из варианта 13 `[11, 7, 14, 20, 5, 1, 15, 9]`, пустой массив, нулевой указатель, один элемент, два элемента, уже отсортированный массив, массив в обратном порядке, дубликаты и отрицательные числа, одинаковые элементы, тип `double`, тип `std::string`, сравнение с `std::sort` на массиве из 1000 элементов.

## Запуск

Открыть `SortingAlgorithms.sln` в Visual Studio и собрать решение (Ctrl+Shift+B). Тесты запускаются автоматически после сборки проекта Tests (событие после сборки `"$(TargetPath)"`), результат выводится в окно «Вывод».
