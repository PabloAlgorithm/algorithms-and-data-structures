# Проверки лабораторной № 1, вариант 13

В таблице кавычки ограничивают строку и не входят в данные. Видимые двойные
пробелы — часть ожидаемого результата. Сценарии алгоритма повторяются для
массива, C-строки и файла.

| Сценарий | Ввод | Ожидаемый результат |
|---|---|---|
| Пустой ввод | `""` | `""` |
| Нет слов | `"123!?"` | `"123!?"` |
| Только разделители | пробелы и табуляция | без изменений |
| Ровно 5 английских букв | `"brick"` | `"brick"` |
| Ровно 5 русских букв, 10 байтов | `"книга"` | `"книга"` |
| 6 букв, согласная | `"planet"` | `""` |
| Удаление в начале | `"planet cat"` | `" cat"` |
| Удаление в середине | `"cat planet dog"` | `"cat  dog"` |
| Удаление в конце | `"cat planet"` | `"cat "` |
| Максимум начинается с гласной | `"elephant planet"` | без изменений |
| Равные длины, первое с гласной | `"orange planet"` | без изменений |
| Равные длины, первое с согласной | `"planet orange"` | `" orange"` |
| Регистр | `"МАШИНА"` | `""` |
| Ё — гласная | `"Ёлочка"` | без изменений |
| Й — согласная | `"йогурт"` | `""` |
| Ё внутри слова | `"жёлтый"` | `""` |
| Ь/Ъ входят в слово | `"вьюнок"`, `"съезды"` | пустая строка |
| Русские и английские слова | `"книга planet"` | `"книга "` |
| Пунктуация сохраняется | `"машина,кот!"` | `",кот!"` |
| Цифры разделяют слова | `"123planet456"` | `"123456"` |
| Дефис разделяет слова | `"planet-rocket"` | `"-rocket"` |
| Символ из 4 байтов | `"😀машина😀"` | `"😀😀"` |
| Символ из 3 байтов | `"猫planet猫"` | `"猫猫"` |
| UTF-8 BOM | BOM + `машина` | BOM сохраняется |
| Все гласные | каждая русская/английская гласная обоих регистров + `bcdef` | без изменений |
| Массив без нуля | ровно столько байтов, сколько во входе | корректный результат без чтения за границей |
| Контроль соседнего байта | `planet`, затем контрольный байт | контрольный байт не изменён |
| Нуль C-строки | удаление единственного слова | первый байт `\0` |

Проверки ввода и файлов:

| Сценарий | Ожидание |
|---|---|
| EOF без данных | пустая строка |
| Пустая строка LF / CRLF | пустая строка |
| Последняя строка без перевода | корректное чтение |
| 1023 байта, с LF / CRLF / EOF | успешное чтение |
| 1024 байта, с LF / CRLF / EOF | TooLong |
| Слишком длинная первая строка, затем `cat` | ошибка первой, следующее чтение получает `cat` |
| Все обычные примеры через файл | результат совпадает, вход не изменяется |
| Несуществующий вход | OpenInputError, прежний выход сохранён |
| Переполнение входа | TooLong, прежний выход сохранён |
| Один файл для входа и выхода | SameFile, вход сохранён |
| Несуществующий каталог выхода | OpenOutputError |
| Две строки в файле | обработана только первая |
| Параметры командной строки | заданные имена входа/выхода используются |
| Неверное число параметров | ненулевой код завершения и сообщение |

Это сценарное покрытие, не отчёт инструментального измерения покрытия кода.

## Регрессия: русский ввод в настоящей консоли Windows

Отдельный тест `[console]`: 9 входов для обоих способов чтения (18 сценариев),
273 проверки. Русский и английский текст, Ё, пустой ввод, трёхбайтовый символ,
суррогатная пара UTF-16 и заполнение/переполнение буфера на границах символов.
Основные 489 проверок и 19 запусков с перенаправлением остаются отдельно.
Проверка ввода «Моя машина тут» вручную через интерактивный терминал выполнена
для ArrayProgram и CStringProgram: обе вывели «Результат: [Моя  тут]».
